# 项目概述 - Teaching Manage

## 业务背景

本系统是面向 IT 编程培训机构设计的教学管理平台，旨在解决以下业务需求：

1. **多学科管理** - 支持 3-5 个并行学科的教学管理
2. **学员管理** - 支持 30-100 名学员的管理
3. **作业流程** - 完整的作业提交、评审、评分流程
4. **小组协作** - 支持分组学科的小组管理

## 用户角色

### 管理员 (ADMIN)
- 用户管理（增删改查、批量导入/导出）
- 学科管理（创建、配置、删除）
- 系统监控和统计

### 教员 (TEACHER)
- 课程管理（创建、编辑、删除）
- 作业评审（代码查看、评论、评分）
- 成绩汇总和导出

### 学员 (STUDENT)
- 加入学科
- 小组管理（创建、加入、退出）
- 作业提交（个人/小组）
- 查看成绩和评论

## 核心业务流程

### 1. 学科-课程流程

```
管理员创建学科
    ↓
学员加入学科
    ↓
教员创建课程（设置作业、截止日期）
    ↓
系统通知学员
    ↓
学员提交作业
    ↓
教员评审和评分
```

### 2. 小组协作流程

```
学科设置为分组模式
    ↓
学员A创建小组 → 成为组长
    ↓
学员B申请加入 → 通知组长
    ↓
组长审批（批准/拒绝）→ 通知学员B
    ↓
小组成员共同提交作业
```

### 3. 作业评审流程

```
学员提交作业（ZIP/RAR 文件）
    ↓
系统解压并生成文件树
    ↓
教员使用代码查看器查看
    ↓
教员添加行级代码评论
    ↓
教员给出评分（A/B/C/D/E）
    ↓
学员收到通知查看结果
```

## 功能模块详解

### 用户管理模块

| 功能 | 描述 | 权限 |
|------|------|------|
| 用户列表 | 分页查看用户，支持角色筛选 | ADMIN |
| 创建用户 | 手动创建单个用户 | ADMIN |
| 批量导入 | Excel 模板导入用户 | ADMIN |
| 导出用户 | 导出用户列表到 Excel | ADMIN |
| 个人设置 | 修改个人信息、头像、密码 | ALL |

### 学科管理模块

| 功能 | 描述 | 权限 |
|------|------|------|
| 学科列表 | 查看所有/我的学科 | ALL |
| 创建学科 | 配置学科基本信息和分组设置 | ADMIN |
| 学员管理 | 添加/移除学员 | ADMIN |
| 物理删除 | 级联删除学科及所有关联数据 | ADMIN |

### 课程管理模块

| 功能 | 描述 | 权限 |
|------|------|------|
| 课程列表 | 查看学科下的课程 | ALL |
| 创建课程 | 设置课程内容、作业、截止日期 | ADMIN, TEACHER |
| 日历视图 | 周视图显示，支持拖拽调整时间 | ALL |
| 物理删除 | 级联删除课程及关联提交/评分 | ADMIN, TEACHER |

### 小组管理模块

| 功能 | 描述 | 权限 |
|------|------|------|
| 创建小组 | 在分组学科中创建小组 | STUDENT |
| 申请加入 | 申请加入现有小组 | STUDENT |
| 审批申请 | 组长批准或拒绝申请 | STUDENT (组长) |
| 移除成员 | 组长移除小组成员 | STUDENT (组长) |

### 作业提交模块

| 功能 | 描述 | 权限 |
|------|------|------|
| 提交作业 | 上传 ZIP/RAR 文件 | STUDENT |
| 重新提交 | 截止前可重新提交 | STUDENT |
| 查看提交 | 查看提交列表和详情，默认显示全部（按课程创建时间倒序） | ALL |
| 下载作业 | 下载原始提交文件 | ADMIN, TEACHER |
| 提交看板 | 三列看板视图，默认显示全部（按课程创建时间倒序） | ADMIN, TEACHER |

### 代码评审模块

| 功能 | 描述 | 权限 |
|------|------|------|
| 代码查看 | Monaco Editor 显示代码 | ALL |
| 行级评论 | 在指定行添加评论 | ADMIN, TEACHER |
| 评分 | 给出 A/B/C/D/E 评分 | ADMIN, TEACHER |
| 评论管理 | 编辑/删除自己的评论 | ADMIN, TEACHER |

### 通知模块

| 通知类型 | 触发条件 | 接收者 |
|----------|----------|--------|
| LESSON_PUBLISHED | 新课程发布 | 学科学员 |
| DEADLINE_REMINDER | 截止前 1 天（每天 9:00） | 未提交学员 |
| GRADE_COMPLETED | 作业评分完成 | 提交者 |
| GROUP_APPLICATION | 学员申请加入小组 | 组长 |
| GROUP_APPROVED | 组长批准申请 | 申请者 |

### 数据分析模块

| 功能 | 描述 | 权限 |
|------|------|------|
| 管理员仪表盘 | 用户/学科/课程统计，数字可点击跳转到对应模块 | ADMIN |
| 教员仪表盘 | 课程/评分统计，数字可点击跳转到对应模块 | TEACHER |
| 学员仪表盘 | 我的课程/成绩统计，数字可点击跳转到对应模块 | STUDENT |
| 成绩汇总 | 按学科/课程/学员汇总，默认按学员汇总显示 | ADMIN, TEACHER |
| Excel 导出 | 导出成绩汇总表 | ADMIN, TEACHER |

## 系统特性

### 安全特性
- JWT 认证（24 小时有效期）
- 基于角色的访问控制 (RBAC)
- 速率限制（每 IP 每分钟 100 次）
- 安全头部配置（XSS、点击劫持防护）

### 文件处理
- 支持 ZIP、RAR 格式
- 自动解压并保持目录结构
- 生成文件树 JSON 供前端渲染

### 定时任务
- 截止日期提醒：每天 9:00 检查即将截止的作业

### 前端特性
- 响应式设计
- 权限指令控制
- 通知轮询（30 秒间隔）
- Monaco Editor 代码高亮

## 技术约束

1. **数据库** - 使用 SQLite，单文件存储，适合中小规模
2. **文件存储** - 本地文件系统，存储在 `./uploads/` 目录
3. **并发** - 适合 30-100 用户同时使用
4. **部署** - 单机部署，前后端可分离部署
