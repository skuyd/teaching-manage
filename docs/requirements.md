## 1. 项目概述

### 1.1 项目背景

本系统面向小型 IT 编程培训机构，用于管理教学进程及跟踪学员作业完成情况。系统支持 3-5 个并行学科，30-100 名学员的全流程教学管理。

### 1.2 项目目标

- 实现培训课程的数字化管理
- 提供便捷的作业提交与评分流程
- 支持个人和小组两种教学模式
- 提供直观的教学进度跟踪

### 1.3 用户规模

| 指标 | 数量 |
|------|------|
| 并行学科数 | 3-5 个 |
| 学员人数 | 30-100 人 |
| 教员人数 | 3-10 人 |
| 管理员人数 | 1-3 人 |

### 4.2 学科管理模块

#### 4.2.1 学科与课程的关系

```
学科 (Subject) —— 一门完整的课程体系
    │
    ├── 课程 1 (Lesson) —— 具体的教学单元
    │       └── 作业提交 (Submissions)
    │
    ├── 课程 2 (Lesson)
    │       └── 作业提交 (Submissions)
    │
    └── 课程 N (Lesson)
            └── 作业提交 (Submissions)
```

**核心概念：**
- **学科**：代表一门完整的课程体系，如"Java 基础"、"前端开发"
- **课程**：学科下的具体教学单元，每次上课对应一个课程
- **关系**：一个学科包含多个课程，每个课程必须属于某个学科
- **学员加入**：学员只能加入学科，不能单独加入课程；加入学科后，自动参与该学科下的全部课程
- **视图入口**：课程视图只能从学科详情页进入，不提供独立的课程列表入口

#### 4.2.2 学科管理功能

| 功能 | 描述 |
|------|------|
| 学科列表 | 卡片式展示学科 |
| 创建学科 | 填写学科信息 |
| 编辑学科 | 修改学科信息 |
| 删除学科 | 物理删除（见删除规则） |
| 学科详情 | 查看学科信息和课程日历视图 |
| 学员管理 | 添加/移除学科学员 |

#### 4.2.3 学科删除规则

| 场景 | 处理方式 |
|------|----------|
| 学科下无课程 | 直接物理删除学科 |
| 学科下有课程，课程下无作业 | 弹出确认框，确认后物理删除学科及所有课程 |
| 学科下有课程，课程下有作业 | 弹出确认框，显示课程和作业数量，确认后物理删除学科、课程及所有作业数据 |

**确认框内容示例：**
```
确认删除学科"Java基础"？

该学科包含：
- 课程数量：12 个
- 作业提交：45 份
- 评分记录：38 条

删除后以上数据将被永久删除，无法恢复。
```

#### 4.2.4 学科数据结构

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | Long | 自动 | 学科ID |
| name | String | 是 | 学科名称 |
| description | Text | 否 | 学科介绍（支持 Markdown） |
| isGrouped | Boolean | 是 | 是否分组教学 |
| minMembers | Integer | 是 | 小组最小人数（分组时） |
| maxMembers | Integer | 是 | 小组最大人数（分组时） |
| startDate | Date | 否 | 开始日期 |
| endDate | Date | 否 | 结束日期 |

#### 4.2.4 学科-学员关联

| 字段 | 类型 | 说明 |
|------|------|------|
| subjectId | Long | 学科ID |
| studentId | Long | 学员ID |

### 4.3 课程管理模块

#### 4.3.1 课程访问入口

**重要说明：** 课程属于学科，因此课程视图只能从学科详情页进入，系统不提供独立的课程列表菜单。

```
访问路径：学科管理 → 学科卡片（点击详情）→ 课程日历视图
```

#### 4.3.2 课程管理功能

| 功能 | 描述 |
|------|------|
| 课程列表 | 日历视图展示（月视图/周视图） |
| 创建课程 | 在日历中点击日期创建 |
| 编辑课程 | 修改课程信息 |
| 删除课程 | 物理删除（见删除规则） |
| 拖拽调整 | 拖拽课程调整上课时间 |
| 课程详情 | 查看课程内容和作业要求 |

#### 4.3.3 课程删除规则

| 场景 | 处理方式 |
|------|----------|
| 课程下无作业 | 直接物理删除课程 |
| 课程下有作业 | 弹出确认框，显示作业情况，确认后物理删除课程及所有关联数据 |

**确认框内容示例：**
```
确认删除课程"第3课：面向对象编程"？

该课程包含：
- 作业提交：8 份
- 评分记录：6 条
- 代码评论：15 条

删除后以上数据将被永久删除，无法恢复。

[取消] [确认删除]
```

**删除时清理的数据：**
- 课程记录 (t_lesson)
- 作业提交记录 (t_submission)
- 评分记录 (t_grade)
- 代码评论 (t_code_comment)
- 相关通知 (t_notification)
- 上传的文件 (uploads 目录)

#### 4.3.4 日历视图要求

| 视图 | 描述 |
|------|------|
| 月视图 | 按月展示课程，每天显示课程标题 |
| 周视图 | 按周展示课程，显示详细时间 |
| 拖拽功能 | 支持拖拽课程到其他日期/时间 |
| 新建课程 | 点击日期新建，默认时间 9:00 |

#### 4.3.5 课程数据结构

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | Long | 自动 | 课程ID |
| subjectId | Long | 是 | 所属学科ID |
| title | String | 是 | 课程标题 |
| content | Text | 否 | 教学内容（支持 Markdown） |
| lessonTime | DateTime | 是 | 上课时间 |
| homeworkDesc | Text | 否 | 作业要求（支持 Markdown） |
| submitType | Enum | 是 | 提交类型：PERSONAL/GROUP |
| deadline | DateTime | 否 | 作业截止时间 |
| allowLate | Boolean | 是 | 是否允许补交 |

## 5. 非功能性需求

### 5.1 安全性要求

| 要求 | 实现方式 |
|------|----------|
| 身份认证 | JWT Token，24 小时有效期 |
| 密码安全 | BCrypt 加密存储 |
| 权限控制 | Spring Security + 角色注解 |
| 跨域保护 | CORS 配置 |
| 请求限流 | 每 IP 每分钟 100 次 |
| XSS 防护 | 安全响应头配置 |
| SQL 注入 | MyBatis 参数绑定 |

### 5.2 性能要求

| 指标 | 要求 |
|------|------|
| 页面响应时间 | < 2 秒 |
| API 响应时间 | < 500ms |
| 文件上传 | 支持 100MB |
| 并发用户 | 支持 50 人同时在线 |

### 5.3 可用性要求

| 要求 | 描述 |
|------|------|
| 浏览器兼容 | Chrome、Firefox、Edge 最新版 |
| 屏幕适配 | 最小宽度 1280px |
| 操作反馈 | 所有操作需有成功/失败提示 |
| 数据验证 | 前后端双重验证 |

### 5.4 数据要求

| 要求 | 描述 |
|------|------|
| 数据备份 | SQLite 数据库文件备份 |
| 逻辑删除 | 所有删除操作为逻辑删除 |
